Model MethodologyA layered read, not a single number — category baseline, player-specific signal, and fixture context are weighted and blended into the probability shown on each card.
GoalsModel projection

Each player's own scoring rate (goals per 90) is run through a Poisson model for the odds of scoring in this week's matchup. Fixture context layers on top, scaled to how the market itself prices the matchup. Ranked league-wide, not one player per club.

AssistsModel projection

Same treatment as Goals, run on each player's assist rate instead — a Poisson read on the odds of setting one up in this week's matchup, plus fixture context. Ranked league-wide, not one player per club, so a couple of clubs without a top producer won't appear on this tab.

Clean SheetsModel projection

Offered only for starting goalkeepers, one per club, framed as the probability their team keeps a clean sheet — under 0.5 goals conceded — in this week's matchup. Built from each keeper's own clean-sheet rate, blended with a neutral prior to protect against a small sample; fixture context runs the same way here — a favorable matchup is protective, a tough one exposing.

Fixture TierMarket-derived

Every fixture adjustment used above traces back here: a team's implied strength for the matchweek, extracted from the market's own three-way price with the house edge stripped out, then bucketed into a tiered nudge rather than applied as a raw number.
