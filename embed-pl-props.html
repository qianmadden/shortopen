Model MethodologyA layered read, not a single number — category baseline, player-specific signal, and fixture context are weighted and blended into the probability shown on each card.
Goals / AssistsForm-weighted

Starts from a category baseline, then leans on recent production — output above a player's own first-goal-or-assist threshold this season nudges the read up, within a modeled ceiling. Fixture context layers on top, scaled to how the market itself prices the matchup. No player gets a hand-set number — proven top scorers simply clear the ceiling on form alone.

Clean SheetsInverted read

Framed as the goals-conceded side of the same coin, so direction stays consistent with the categories above it. A team's defensive track record this season pulls the number down as it accumulates; fixture context runs the opposite way here — the model treats being favored as protective, not exposing.

Passes CompletedVolume-set line

The line itself is derived rather than fixed — anchored just above a player's own season volume so the read leans slightly toward the under before any other signal is applied. Fixture context is the only adjustment layered in beyond that starting point.

Fixture TierMarket-derived

Every fixture adjustment used above traces back here: a team's implied strength for the matchweek, extracted from the market's own three-way price with the house edge stripped out, then bucketed into a tiered nudge rather than applied as a raw number.
