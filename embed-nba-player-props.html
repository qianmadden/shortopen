Model MethodologyThe short open model blends three visible inputs into the probability shown on each card — nothing is a hidden black box.
Scoring BaselineSeason avg

Every read starts from the player's own season-long points per game, built from aggregated league data — the anchor the rest of the model adjusts around.

Efficiency SignalTS% weighted

True shooting percentage nudges the read up or down from that baseline — an efficient high-volume scorer clears the line more consistently than a volume-only scorer with the same average.

Usage AdjustmentRole-scaled

Usage rate scales how much offensive control a player actually holds, tightening or loosening the read to reflect how central they are to the offense on a given night.

Line SettingModel-derived

The points line itself is set just below the player's season average, giving our own formula a consistent over/under frame to price against for every player on the board.
